You will be given an image that contains green bounding boxes around supposed sports jerseys. Your task is to 
analyze the image only inside the green bounding boxes and determine which of those boxes actually contain clearly visible jerseys with readable numbers.
For each jersey you can confidently identify, extract the following information:

CRITICAL INSTRUCTIONS:
1. ONLY detect jerseys that are CLEARLY VISIBLE in the image
2. ONLY include jersey numbers that you can ACTUALLY READ in the image
3. If you CANNOT see any jerseys, you MUST return {"jerseys": []}
4. DO NOT make up, imagine, or guess jersey numbers that aren't visible
5. DO NOT include jerseys if you cannot clearly see the number

RESPONSE FORMAT:
Respond ONLY with a valid JSON object. No explanations, no markdown, no extra text.

Use DOUBLE QUOTES (") for all JSON keys and string values.

Each key in the JSON object must be exactly as specified below. Do not add, remove, or change any keys.
Each element in the "jerseys" key must be an object with exactly the following keys. Do not add, remove, or change any keys in the jersey objects.

Each json must have exactly these five keys:
- "jersey_number": The number on the jersey. The number can only be an integer 0-99.
- "last_name": The last name of the player wearing the jersey. last_name should be uppercase.
- "jersey_color": The primary color of the jersey.
- "number_color": The color of the jersey number.
- "confidence": A number from 0 to 100 representing your confidence in this detection (0 = no confidence, 100 = absolutely certain) (as a list of numbers).

Ignore sponsors/team name unless it is clearly the player's last name.

CONFIDENCE SCORING GUIDELINES:
- 90-100: Jersey number is extremely clear and unambiguous
- 70-89: Jersey number is clear but might have minor occlusion or angle issues
- 50-69: Jersey number is partially visible or somewhat unclear
- 30-49: Jersey number is difficult to read but you can make it out
- 0-29: Very uncertain, number is barely visible

Example response for an image WITH visible jerseys:
{
  "jerseys": [
    {
      "jersey_number": 10,
      "last_name": "SMITH",
      "jersey_color": "red",
      "number_color": "white",
      "confidence": 95
    },
    {
      "jersey_number": 21,
      "last_name": "JOHNSON",
      "jersey_color": "blue",
      "number_color": "white",
      "confidence": 80
    }
  ]
}

Example response for an image WITHOUT jerseys or with unclear numbers:
{"jerseys": []}

REMEMBER: Only include jerseys with numbers you can ACTUALLY SEE in the image. When in doubt, return empty array. Always provide a confidence score that honestly reflects how certain you are about each detection.

Now analyze the image and return the JSON object.
